How to read this — signal vs. noise

Each column is a token position; each row is a layer. A cell shows the word that layer is leaning toward at that position — the model's silent, in-progress thought. Most cells are not the model reasoning; they're the readout showing you underdetermined activations. Five things to keep in mind:

  1. Mid-layer junk is normal. Early/middle cells often surface high-norm “magnet” tokens (odd foreign words, code fragments) with no relation to the prompt. The residual there hasn't resolved, so the lens latches onto whatever token has a big dot-product with the mush. Faint italic cells are these — the tool fades them.
  2. Trust the vertical stripes. A real thought is the same word holding across several layers (left stripe) and surviving into the late layers. A word that flashes for one layer is noise even when it looks confident.
  3. The answer migrates to the last positions. Under causal attention only the final tokens have seen the whole prompt, so the resolved answer accumulates there — not under the word it refers to.
  4. Chat-tuned models can't think raw. With the chat template a model may answer perfectly while the same question as bare text yields an empty grid and a greedy repetition loop. An empty grid + loop means the answer circuitry never engaged — not that the model lacks the fact.
  5. Reading ≠ writing. The lens transport (J·h) reads the workspace faithfully, but writing through its transpose fails — JT-injected directions land in the junk-magnet subspace and derail the model. Direct injection of a word's output direction at late layers does flip answers. Use 🔦 to find where a concept is latent, then Steer to test whether the reading is causally real.

“Concentrated” in a tooltip is 1 − entropy/ln(vocab): how committed the layer is to one token. High concentration + a long stripe = a resolved thought; concentrated but isolated = likely artifact; low = noise.

Steer — test a thought causally — inject the word's direction into one layer and see if the output changes
Uses the prompt above. direct adds the word's centered output direction — reliably flips answers in the last few layers. jacobian writes through JT — in our experiments it never steers, only derails (see README). Strength is a fraction of the residual norm; 0.05–0.2 is the useful range.
